# Hypnokort

- Läs `docs/arbetsanteckningar.md` före innehållsändringar. Användarens beslut ska bevaras.
- Detta repo är separat från `wglitch/Frasbanken`.
- Svenska genomgående. Naturlig svenska, konkreta språkgrepp, användarens formuleringar prioriteras.
- ”SVARA PÅ” (tidigare ”Svara på:”) används endast på N-kort, inte på hypnos-/Miltonkort eller generellt i övningarna.
- Inbäddade uppmaningar: slumpa kommandot, låt användaren skapa ramen, egen utvärdering. Visa inte ett facit före försöket.
- MUS betyder Mening utan slut. Flagga inte avsiktlig svårföljd helhet som dåligt språk.
- Ingen AI-analys eller hemliga API-nycklar i version 1.
- Statisk webbapp på GitHub Pages. Behåll relativa resurssökvägar, inga serverkrav.
- Favoriter och anteckningar lagras lokalt och ska tåla saknad localStorage.
- Inga godtyckliga garantier om hypnoseffekt.
- Ingen subagentdelegering krävs.

- Godkänd layout: ljus helskärm, vänsterställd text. På N-kort liten versal SVARA PÅ nära stor fras och mindre förklaring i meningsform. Stilla op-art cirka 50 procents opacitet; virvelns centrum vid uppmaningen.
